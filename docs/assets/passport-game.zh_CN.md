# Passport OS 小游戏

日期：2026-10-23。状态：完整横版卷轴平台跳跃游戏，位于 `feature/passport-os-v0.1`，已加入碰撞修复和手动操作优化；最初的隔离开发分支 `feature/passport-game` 已成为历史。

## 目的

在 Passport OS 身份卡的功能菜单里提供一个超级马里奥风格的横版卷轴平台跳跃游戏。离线单人，三个按键，不依赖 Wi-Fi、USB 或音频。设计参考经典 1-1 关卡的结构——问号砖、砖块排、水管、深坑、双子阶梯、旗杆与城堡——但布局、美术与数值均为原创。

## 横屏方向与按键

240x320 的竖屏面板逆时针横握，游戏视口即为熟悉的 320x240 横屏。游戏坐标系的矩形 `(gx, gy, gw, gh)` 绘制在屏幕 `(239 - gy - gh, gx)`，宽高互换；文本标签绕中心旋转 90 度，横握时依然正立可读。

| 按键 | 游戏内行为 |
| --- | --- |
| UP | 向左走 |
| DOWN | 向右走 |
| OK 短按 | 跳跃（固定满高弧线）；在准备/通关/结束画面上是确认键 |
| 空中再按 OK | 额外一次二段跳 |
| OK 长按 2 秒 | 返回身份卡（全局快捷方式） |

### 共用 ADC 按键与跳跃容错

三个按键共用 ADC 电阻梯。UP 会把节点接地，遮住 OK 和 DOWN；DOWN+OK 则有不同的理论电压（约 212 mV，单独 DOWN 约 300 mV），仅在游戏拥有输入时识别为两键同时按下。初始可配置窗口为 170–250 mV，这些数值来自电路定义，仍需真机实测。其他页面继续使用单键识别。

- 可以一直按住 DOWN 再按 OK 右跳，也可以两键一起按。UP+OK 在电气上无法区分：左跳时先松开 UP，再迅速按 OK。松方向键后 120 毫秒内起跳保留松键时的速度，按另一方向会取消这项补偿。
- 按下 OK 即执行满高跳跃；松开 OK 不截断弧线。走出平台边缘后保留 100 毫秒地面起跳机会，不消耗二段跳。
- 空中动量保留、空中转向常开：跳跃中松开方向键不减速，空中按方向键只转向、绝不缩短弧线。
- 空中额外提供一次二段跳，每次落地与踩踏弹起都会重新武装，保证高水管与旗杆顶端奖励可达。
- 二段跳用完后，提前按跳可等待最多 120 毫秒，落地自动起跳一次；一直按住 OK 不会自动连跳。输入丢失时清空方向与待执行动作，并等所有键松开后恢复。

## 机制

- 行走带加速度、转向打滑与地面摩擦，速度有上限。摄像机只向右跟随、从不回卷，视口左缘像经典作品一样挡住角色。
- 顶问号砖出金币（+200，计币数）或蘑菇（+1000）；蘑菇从砖内升起、行走，吃到后变大。变大后被撞一次只缩小并进入 2 秒无敌闪烁，而不是死亡。
- 砖块可从下方顶碎（+50，四块碎片飞散）。场景金币碰到即收（+200）。
- 蘑菇怪朝角色走来、撞墙折返、会掉进坑。怪物和蘑菇下落时落在首先经过的表面，即使延迟帧跨过两层地砖也不会落进下层。从上方踩扁（+100，压扁动画并弹起，弹起同时重新武装二段跳）；侧面接触则受伤。
- 三条命。深坑、敌人与倒计时都会致死；时间每 400 ms 走一格，通关一轮后下一轮时间更少、蘑菇怪更快。
- 扒旗杆（高度 ×100 奖励），观看滑杆、走进城堡的演出，剩余时间 ×10 计入分数，之后 OK 进入下一轮，保留变身与分数。
- 最高分仅保存在内存中，重启局保留、断电清零；本迭代刻意不做持久化。

## 实现

- `main/passport_game.c` / `main/passport_game.h`：纯逻辑、确定性的 Q8 定点仿真——不依赖浮点、LVGL、ESP-IDF。关卡由分段/水管/出生点表格生成（212 列）；基于瓦片的碰撞配合移动子步进（不隧穿）；顶砖交互、蘑菇怪/蘑菇/弹出金币/碎片实体、摄像机、生命与轮次状态机。由 `tests/test_passport_game.c` 覆盖，含逐位一致性（确定性）检查。
- `main/passport_ui.c`：旋转坐标系下的 LVGL 渲染。整个游戏画面由一个对象的 `LV_EVENT_DRAW_MAIN` 处理器用 `lv_draw_rect` 绘制——瓦片按行游程合并填充，水管、旗杆、城堡、金币、蘑菇怪、蘑菇、碎片与五部件角色全部化为世界坐标矩形，经四分之一旋转变换映射到竖屏面板。画家之上只有十个控件：四个旋转 HUD 标签、覆盖层面板和四个旋转覆盖层标签，均带字段缓存。渲染器只读游戏视图，从不修改游戏状态。控件数压到这么低，是因为共享的 LVGL 内存池（现为 64 KB，见下）还要容纳其他所有页面。
- 旋转文本经 LVGL 的 transform 层绘制：每个旋转标签先渲染到一块约"长 × 高 × 4"字节的临时 ARGB8888 缓冲，从 LVGL 池分配。游戏页存活时该峰值超出 32 KB 池的承受范围，而 LVGL 9.5 单线程 SW 绘制单元对分配失败的临时层会无限重试（表现为满占 CPU 的卡死而非崩溃）。因此 `sdkconfig.defaults` 把 `CONFIG_LV_MEM_SIZE_KILOBYTES` 从 32 提到 64——ESP32-C3 开机后仍余约 90 KB 空闲堆——`tools/preview/CMakeLists.txt` 同步镜像该值，让主机预览跑在与固件相同的预算下。标签先沿长轴排版、再绕中心旋转：长 `gw`、行高 `gh` 的横屏标签就是一个普通的 `gw × gh` 标签，旋转后矩形与未旋转标签的中心重合。
- `main/passport_model.c` / `main/passport_app.c`：GAME 页转发原始边沿，启用 BSP 的 DOWN+OK 组合识别，并在丢失输入所有权时清空状态。游戏模型只跟踪 OK，方向键不再干扰长按 OK 返回主页。
- `assets/passport/ui-text.json` 以及重新生成的 `passport_strings.h`、`manifest.json` 添加中文 HUD/覆盖层文案；全部字形已由 GB2312 字体子集覆盖。

## 验证

遵循仓库门禁：`./tools/validate.sh --static`（仓库检查、主机测试和真实 LVGL 预览）与 `./tools/validate.sh --firmware`（ESP-IDF 5.5.3 构建和合并镜像校验）。主机回归覆盖原关卡 51/52/60 毫秒怪物掉落、蘑菇落地、水平小数、跳跃时间窗口、输入恢复，以及模拟电压下的真实 BSP 解码。组合键真实电压稳定性、横握手感和屏幕渲染仍属于硬件验收项。
