# Passport OS 视觉规范

给后续修改工牌 UI 的人参考。新增界面请遵循这些规范；布局几何集中在
`main/passport_ui.c` 顶部的 `#define` 常量（视觉标记）里，改一个布局值只动一处。

## 配色

| 标记 | 色值 | 用途 |
| --- | --- | --- |
| 背景上/下 | `0x0e2a4a` → `0x0a1c33` | 屏幕纵向渐变 |
| 面板 | `0x0c1d3a` | 卡片、按钮、菜单行 |
| 轨道 | `0x1a4a6e` | 边框、未激活条 |
| 主文字 | `0xf4faff` | 主要文字 |
| 次要文字 | `0x8fa3c0` | 次要文字、未选中按钮 |
| 强调绿 | `0x3dff9e` | 强调、选中、标题色 |
| 白画布文字 | `0x0a1c33` / `0x4a5a76` | 白色图片页上的文字 |
| Nora 画布 / 字幕 | `0xffffff` / `0x222222` | 全屏智能体，必要提示为灰色 |
| 电量低 / 中 | `0xff5a5a` / `0xffcf3f` | 低于 20% / 低于 50%；否则绿色 |

## 字体

| 部件 | 字体 |
| --- | --- |
| 时钟 | Montserrat 28 |
| 星期、电量、按钮、图标、TEMP | Montserrat 14 |
| 主页姓名、单位/身份 | `passport_font_24_bold`，Noto Sans SC 700 字重、2 bpp |
| 研究方向、标题、菜单行、Nora 字幕 | `passport_font_20` |
| 提示 | `passport_font_16` |

资料字体是生成的子集（个人构建含 GB2312）；USB 保存会拒绝字库之外的字符。

## 区域

- 状态栏 `y 0–30`：时钟 + 星期（靠左、相邻），电量数值 + 电池图标（靠右）。
  图片、游戏和 Nora 页隐藏。
- 主体 `y 30–320`：徽章、菜单、亮度、关于、任务结果和笔记；图片、游戏及 Nora
  整屏绘制。
- 徽章：头像 `76x150`（竖版，信息在其右侧居中）或 `216x112`（横向，信息在
  下方居中）；AGENT / QR 为 `108x44` 的横向图标加文字按钮，主体内 `y 236`。
  文字行高度不小于字体行高。
- 菜单：七行 `216x44`，从 `y 32` 起，行距 `50`；视口一次显示四行。
- 图片页：全屏 `240x320`，白底画布，图片从 Flash 内存映射。
- Nora 页：全屏 `240x320` 纯白，仅显示 `Nora` 姓名、居中的 `128x132` 原生动画、
  20 像素字幕和必要小提示。无系统栏、卡片边框、音量柱及长按返回提示；实际
  长按 OK 导航保留。配对确认文字完整放入字幕窗口。

## 交互

徽章页上/下键在 AGENT/QR 之间移动高亮，确定键进入高亮项（AGENT → 智能体，
QR → 图片页）。图片页按确定返回。身份卡页长按确定两秒打开隐藏菜单；其他页面
同样长按返回身份卡页。菜单页上/下移动行高亮，确定键进入。智能体、任务结果和
笔记页用上/下键翻阅文字或切换笔记，确定键执行页面动作。

## 文字溢出

资料字段按实际文字宽度判断：放得下时居中静止，超宽时才以 28 px/s 左右往返滑动，
两端停留。竖向和横向头像布局的文字框高度均不小于字体行高，不出现上下跑马灯。
研究方向的换行在此单行显示中变为空格，不改保存的资料。其他标签用省略号截断，
未覆盖的字符显示字形缺失占位符。

## 头像动画

可选个人角色包在固定位置、固定透明度下换帧，表现待机呼吸/眨眼、关注目标和轻点头。
切换高亮保留头像对象。上传的单张图片保持静态；公共中性临时头像可眨眼并显示 `TEMP`。
不使用运行时变换或整帧解码缓冲，详见[动画接入说明](passport-motion.zh_CN.md)。

## 电池图标

电池图标填充宽度跟随上报的百分比并变色：≥50% 绿色，低于 50% 黄色，低于
20% 红色。电量读不到时显示 `--%`，填充为空。
